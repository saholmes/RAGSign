# RAGSign
Retrieval Augmentation Generation  (RAG) Sign 

This is the Files and programs associated with the RAGSign paper that highlights how to create a unique identity for a RAG enabled LLM and use this unique identity to enable a signing keypair to be created, enabling every LLM output message to be signed by this signing key and the output meessage verified via the pk that it came from this RAG enabled LLM.  

We also enable the RAG system to decide through a set of white linsted public keys if a request is authorised to use the RAG database alongside the LLM of choice.  This protects disclosure of RAG information to unauthorized parties.  

Finally, we can use the signing of the messages to banish a rogue RAG enabled LLM from the internet.  Providing a Kill switch for LLMs and AI systems.
